# SQL Retail & Sales Data Analysis Project

## Overview
This project was completed as part of a **Data Technician Bootcamp** and focuses on analysing retail and sales data using **SQL**. The goal was to explore relational databases and extract meaningful insights from structured datasets by writing queries to retrieve, filter, and aggregate data.

Using the **Northwind sample database**, the project demonstrates how SQL can be used to analyse customers, orders, products, and sales performance within a relational database system. :contentReference[oaicite:0]{index=0}

---

## Key Skills Demonstrated

### SQL Query Writing
Developed strong foundational SQL skills by writing queries to retrieve and analyse data:

- `SELECT` – Retrieve specific columns and datasets from database tables  
- `WHERE` – Filter records based on conditions  
- `ORDER BY` – Sort query results for easier analysis  
- `GROUP BY` – Aggregate data to summarise key metrics  
- `DISTINCT`, `COUNT`, `SUM`, `AVG`, `MIN`, `MAX` – Perform data aggregation and statistical analysis

These queries enabled the extraction of valuable information from large datasets. :contentReference[oaicite:1]{index=1}

---

### Working with Relational Data
Used **table JOINs** to combine related datasets and analyse relationships between different entities.

JOIN types used include:

- **INNER JOIN** – Retrieve records with matching values in both tables  
- **LEFT JOIN** – Identify records without matching relationships  
- **RIGHT JOIN** – Ensure all records from a specific table are included  
- **CROSS JOIN** – Generate combinations between datasets  

These joins allowed analysis across multiple tables such as **customers, orders, products, and suppliers**. :contentReference[oaicite:2]{index=2}

---

### Data Analysis Techniques
SQL queries were used to extract insights such as:

- Total sales by product
- Number of orders handled by employees
- Customer distribution by country or city
- Quantity of products sold by category
- Sales performance ranking using sorted results

By aggregating and grouping data, the project demonstrates how SQL supports **business intelligence and operational analysis**.

---

## Database Structure
The analysis used a **relational database structure** with interconnected tables, including:

- **Customers** – customer details and locations  
- **Orders** – purchase transactions  
- **Products** – product catalog and pricing  
- **Order Details** – quantities of products sold  
- **Employees and Shippers** – order handling and delivery

Relationships between tables were established using **primary and foreign keys**, enabling efficient data retrieval and ensuring data integrity. :contentReference[oaicite:3]{index=3}
